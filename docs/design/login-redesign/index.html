Bejelentkezés — 3 design variáns

Mindegyik önálló HTML mockup: nyisd meg, méretezd át, nézd mobilon. A kiválasztott változat közvetlenül átemelhető a valódi login page-be.

1. VARIÁNS

Platform split-screen

Sötét teal márkapanel + űrlap. Az „egy platform, két világ" üzenet: master brand, két termék-kártya, bizalmi sor. A klasszikus, légies 2026-os B2B SaaS felépítés.

Megnyitás → 2. VARIÁNS

Minimal — sötét mód

Linear-stílusú, középre zárt kártya sötét háttéren, teal fény-akcenttel. A legkevesebb elem, a legnagyobb nyugalom — fejlesztői és tech-vásárlói ízlésre.

Megnyitás → 3. VARIÁNS

Termék-bemutató (interaktív)

Világos, vállalati tiszta felosztás — a bal oldalon Docs/HR fülváltóval, ami élőben váltja az értékajánlatot. Felfedezi a „két külön termék" lehetőséget.

Megnyitás → 4. VARIÁNS · KIVÁLASZTOTT IRÁNY

Középre zárt platform

Az 1-es márkatartalma („Egy platform. Két világ.", Docs/HR kártyák, bizalmi sor) — de minden egy középre zárt oszlopban, teal-degradált háttéren, átmeneti kártyával.
